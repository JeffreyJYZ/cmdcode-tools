# Report — a guard with no replacement on PATH

## Scope

Repo-only change. Live `~/.config/opencode/shell-rc.json`, `~/.config/opencode/shell.zsh`
and the state dir were not touched. The shipped 0.4.2 plugin keeps its working
`echo`-prefixed `tccutil` entry. All proof below runs against a temporary HOME.

## Diff summary

- `src/guards.ts`: `renderGuards` no longer skips an entry whose replacement's first
  word is not installed. A blank value is still skipped. When the first word resolves
  on PATH the line is unchanged (`— use <replacement>`); otherwise the value is used
  verbatim as the refusal (`— <replacement>`, no `use`). Doc comment updated.
- `test/guards.test.ts`: replaced the "skips a missing binary" test with two cases —
  installed first word keeps `use`, missing first word writes the function with the
  sentence and no `use`. Added a blank-value case, a `syncGuards` case writing the
  sentence with no binary on PATH, and a real-zsh case proving the generated function
  refuses with status 127 and its own message.
- `test/shim.test.ts`: made `XDG_CONFIG_HOME` temp-scoped, and added a case proving a
  JSON edit reaches `guards.zsh` through `prepare()` while `state.zsh` stays byte-identical
  (no state refresh, no opencode restart).
- `AGENTS.md`: corrected the stale "not on PATH is not written" clause and added one
  bullet for the new case. Bullet count 26 → 27.

`DEFAULT_BLOCKED` stays empty. The `cat` exclusion and `validName` check are unchanged.

## Proof against a temporary HOME

Config written into the temp HOME:

```json
{ "blocked": { "tccutil": "TCC changes are human-only; ask the user" } }
```

`syncGuards(() => false)` returned `true`. Generated
`$XDG_STATE_HOME/opencode/shell-rc/guards.zsh`:

```zsh
# Generated by opencode-shell-rc. Sourced by agent shells only.
unalias tccutil 2>/dev/null
function tccutil {
  print -u2 -- "tccutil is blocked in agent shells — TCC changes are human-only; ask the user"
  return 127
}
```

Sourced in a fresh `zsh -f` and called as a command (no real `tccutil` ran):

```text
status=127
tccutil is blocked in agent shells — TCC changes are human-only; ask the user
```

This is what the generated function itself does. As with the `grep` guard, a zsh
function only shadows what the model types: `command tccutil`, `/usr/bin/tccutil`
and `sh -c tccutil` are not covered by it. No such command was run here.
