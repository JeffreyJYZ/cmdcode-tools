# Lane F — `oduse`: fetch OpenDesign's published prices live instead of trusting a baked table

Repo `/Users/jyz/dev/cmdcode-tools`. Rust workspace: `core/` (`cmduse-core`), `cmduse/` (bins `cmduse`,
`ocuse`, `arkuse`, `oduse`).

## The defect

`core/od.json` — 46 model rows of token rates and credit multipliers — is baked into the binary with
`include_str!` (`core/src/lib.rs:57`) and regenerated by `scripts/extract-od-rates.ts`. So `oduse`'s
pricing is frozen at whatever the last release shipped, while the same publisher serves the live numbers at
`/api/v1/public/model-prices` and `mpc` already reads them at runtime (`oc-cmd-compare/src/data/sources/od/`).
When a plan changes a rate, every dollar and every credit figure `oduse` prints is wrong until someone
notices and cuts a release — the exact failure that just cost the Go side 14 points of accuracy.

## Task

Make the live price list the source and the baked file the offline seed. Do **not** copy ocuse's
implementation — another lane is writing `cmduse/src/ocuse/catalogue.rs` in parallel. Work inside
`cmduse/src/oduse/` only.

1. New module `cmduse/src/oduse/catalogue.rs`:
   - `fetch()` the public model-price payload (find the exact URL and auth requirement from
     `oc-cmd-compare/src/data/sources/od/` — if it needs no key, say so; if it does, take the plan/key
     situation from what that code already does and report what you found).
   - Bounded: a reqwest timeout of ~8 s, one retry on transport error, no retry on 4xx, a `user-agent`.
   - Disk cache under `~/.cache/cmduse/` (env override `CMDUSE_CACHE_DIR`), TTL 6 h, `--cache <dur>` to
     override and `0` to disable. Write only after a parse that produced rows; **never persist an empty
     result**.
   - On failure fall back to `cmduse_core::OD_JSON` and mark the result `builtin`.
2. `cmduse/src/oduse/` keeps its pricing maths untouched; only the table's origin changes. One parse path
   for both sources.
3. Provenance reaches the dashboard, `--json` and `statusline --json` (`live`, `builtin`, `cache, 3h old`).
   A stale fallback must never look fresh.
4. Flag `--no-catalog` (match the naming the oduse CLI already uses; `cmduse/src/oduse/cli.rs` is yours —
   `cmduse/src/cli.rs` and `cmduse/src/ocuse/**` belong to other lanes).
5. The plan-multiplier rows that `od.json` carries and the price payload does not must keep working from
   the baked file — if the two sources cover different halves, merge them and say which field came from
   where. Never invent a multiplier a source does not publish.
6. Update `cmduse/README.md` and `cmduse/cmduse.1` in the same edit.
